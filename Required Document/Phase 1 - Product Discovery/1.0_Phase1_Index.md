# Phase 1 — Product Discovery: Indeks Dokumen

**Proyek:** Harmoni Clothing Website

Dokumen ini adalah peta navigasi untuk 7 dokumen Phase 1. Gunakan ini untuk menemukan "informasi X ada di dokumen mana" tanpa perlu membuka semua file satu per satu.

---

## Daftar Dokumen

| # | Dokumen | File | Isi Singkat |
|---|---|---|---|
| 1.1 | Project Brief | `1.1_Project_Brief.md` | Definisi produk menyeluruh: masalah, solusi, target user, scope, KPI, risiko. Ini adalah **Dokumen akar**, artinya semua dokumen lain merujuk ke sini. |
| 1.2 | Requirement Gathering | `1.2_Requirement_Gathering.md` | Kebutuhan sistem rinci: Functional Requirements (FR), Business Rules (BR), Non-Functional Requirements (NFR), user stories, acceptance criteria. |
| 1.3 | User Persona | `1.3_User_Persona.md` | 3 persona (Rangga/Customer, Nadia/Creator, Pak Budi/Admin) berisi goals, pain points, journey masing-masing + catatan journey singkat Guest. |
| 1.4 | Competitor Research | `1.4_Competitor_Research.md` | Riset 5 direct competitor (Printful, Printify, Redbubble, Threadless, Tees.co.id) + 3 indirect untuk gap analysis & diferensiasi. |
| 1.5 | Feature List | `1.5_Master_Feature_List.md` | **Single source of truth** untuk seluruh 57 fitur (FE-ID), lengkap dengan priority, complexity, value, dependency, technical notes, risks. |
| 1.6 | MVP Definition | `1.6_MVP_Definition.md` | Konfirmasi scope v1.0 (semua 57 fitur, satu rilis), success criteria, launch checklist. |
| 1.7 | Product Roadmap | `1.7_Product_Roadmap.md` | Timeline pengembangan 1 bulan, urutan modul, milestone, resource planning. |

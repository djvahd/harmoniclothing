# Phase 2 — Information Architecture: Indeks Dokumen

**Proyek:** Harmoni Clothing Website

Dokumen ini adalah peta navigasi untuk 5 dokumen Phase 2. Gunakan ini untuk menemukan "informasi X ada di dokumen mana" tanpa perlu membuka semua file satu per satu.

---

## Daftar Dokumen

| # | Dokumen | File | Isi Singkat |
|---|---|---|---|
| 2.1 | Sitemap | `2.1_Sitemap.md` | Seluruh 45 halaman website (Public, Customer, Creator, Admin), URL, hierarki, dan struktur URL. Ini adalah **dokumen akar Phase 2**, seluruh dokumen lain merujuk ke sini. |
| 2.2 | User Roles | `2.2_User_Roles.md` | Definisi 4 role (Guest, Customer, Creator, Admin) tingkat sistem: tanggung jawab, kemampuan, modul yang dapat diakses, hierarki, lifecycle, dan batasan role. |
| 2.3 | User Flow | `2.3_User_Flow.md` | Alur sistem detail untuk 20 flow utama (registrasi, checkout, Bulk Order, KYC Creator, approval, tracking, dst.), termasuk decision point, validasi, exception flow, dan state transition (Order/Payment/Shipment Status). |
| 2.4 | Navigation Structure | `2.4_Navigation_Structure.md` | Struktur menu & navigasi per role, navigation tree, breadcrumb, deep link rules, dan navigasi responsive (desktop/tablet/mobile). |
| 2.5 | Permission Matrix | `2.5_Permission_Matrix.md` | Hak akses granular per role terhadap modul, fitur, halaman, dan API — dasar implementasi Policy/Middleware di Phase 5 & 7. |
